01 / SETUP

安装与启动

Windows 10/11 x64 用户推荐安装版：到 最新正式版下载页，在 Assets 下载 CreatorHub-Setup-版本-windows-x64.exe，双击运行安装向导（支持自定义选择安装目录，如 D 盘等非系统盘；账号与配置数据独立保存），完成后使用快捷方式启动。无需手动安装 Python 或构建源码；缺少 WebView2 时安装器自动联网安装。新版会直接准备工作台，优先复用系统 Chrome，仅在需要时补齐浏览器组件；旧版请点击“启动本地服务”。组件下载时请保持联网，启动中心可查看进度和取消；Source code (zip) 是源码，不是安装程序。后续更新见更新与备份。
源码安装：开发者 / macOS / Linux（Windows 安装版用户跳过）

准备什么？

  • 一台带桌面环境的 Windows、macOS 或 Linux 电脑，以及能正常访问对应平台的网络。
  • Python 3.10 或以上。Windows 安装 Python 时勾选 Add Python to PATH，安装后重新打开终端。
  • 小红书用户建议准备本机稳定版 Google Chrome。首次安装会下载 Python 依赖和浏览器，请预留时间和磁盘空间。

数据库使用本地 SQLite，无需另外安装数据库服务。源码使用小红书 API 读取（当前默认模式）、API 发布兼容模式或前端开发构建时，需准备 Node.js 18+ 并安装项目的 Node.js 依赖；浏览器页面模式不需要先构建前端。媒体处理可选装系统 ffmpeg，未安装时使用 Python 依赖附带的版本。

第一步：下载项目

  1. 打开 GitHub 项目主页。
  2. 点击 Code → Download ZIP，把压缩包完整解压到一个固定文件夹。不要在压缩包里直接启动。
  3. 打开解压后的文件夹，确认能看到 start.cmd、start.sh 和 creatorhub.py。
已经会用 Git？使用克隆方式
git clone https://github.com/3441293738/creatorhub.git
cd creatorhub

克隆方式便于以后更新；ZIP 方式不要求安装 Git。

第二步：运行启动脚本

Windows

在项目文件夹的地址栏输入 powershell 并回车，打开终端后运行下面这一行。使用终端启动，报错时窗口不会一闪而过。

.\start.cmd

macOS / Linux

在终端输入 cd （末尾保留空格），再把项目文件夹拖入终端，回车后运行：

chmod +x start.sh
./start.sh

首次运行会创建 .venv、安装依赖和 Chromium，并从示例生成 config.yaml。看到持续下载日志时请等待，不要反复启动。

第三步：打开本地面板

等待服务启动后，在浏览器打开 http://127.0.0.1:8000。这个地址指的是你自己的电脑，不是公共网站。

完成标志：能看到指挥概览，切换顶部平台或打开“账号矩阵”页面。第一次列表为空是正常的。

以后怎么启动、怎么停止？

下次仍在同一文件夹运行启动脚本。服务运行期间保持终端开启；停止时回到终端按 Ctrl + C。仅关闭网页并不会停止后台服务。

常用启动与开发命令
.\start.cmd install
.\start.cmd --port 8080
.\start.cmd --no-open
.\start.cmd --reload

依次对应安装或更新依赖、换端口、不自动打开网页、开发热重载。换端口后访问 http://127.0.0.1:8080。macOS / Linux 把 .\start.cmd 换成 ./start.sh。

手动安装（不使用启动脚本）
python -m venv .venv

# Windows 激活虚拟环境
.venv\Scripts\activate
# macOS / Linux 激活虚拟环境
source .venv/bin/activate

python -m pip install -r requirements.txt
python -m patchright install chromium
# 复制 config.example.yaml 为 config.yaml，再启动服务：
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

激活命令按操作系统二选一；启动服务保持单 worker。需要小红书 API 通道时，在仓库根目录额外运行 npm install。

02 / ACCOUNT

登录第一个账号

入口：顶部选择平台（或全平台）→ 账号矩阵 → 添加账号

  1. 可在顶部选择要使用的具体平台，或在“全平台 → 账号矩阵”顶部快捷选择目标平台。
  2. 打开“账号矩阵”，点击对应平台的扫码、创作者登录或 Token / Cookie 导入入口。新手建议优先使用扫码登录。
  3. 在一站式登录环境面板确认浏览器内核与代理策略（支持自动分配、从代理池挑选、原地手动输入或本机直连；国内平台若池内仅有境外节点会自动默认选中本机直连），随后在弹出的浏览器窗口按平台提示扫码确认，不要提前关闭登录窗口。
  4. 回到账号矩阵，检查昵称、健康状态与代理归属；必要时刷新资料、划入跨平台矩阵分组或设置角色标识。
完成标志：账号出现在当前平台列表，状态检测正常，并能在创建任务时被选中。
小红书与海外小红书均区分两种登录用途：主站扫码登录用来读取内容与管理本账号作品；需要发布时还要完成独立的“创作者登录”。“能查看笔记”不代表“已经能发布”。海外小红书（rednote.com）建议配置非中国大陆代理出口（支持本机直连或多号复用代理并自动提醒风险，不强制阻断），支持 www.rednote.com 主站扫码、creator.rednote.com 创作者登录与 .rednote.com Cookie 导入，与国内版 xiaohongshu.com 登录态严格隔离、不可混用。
TikTok、Instagram、Twitter、Facebook 与 YouTube 使用独立入口：切换到对应海外平台或在“账号矩阵”快捷添加栏选中平台后，点击登录入口，按提示选择浏览器环境与代理（推荐绑定境外独立代理，也支持本机直连）完成登录；Instagram 支持粘贴含 sessionid 与 csrftoken 的完整 Cookie，Twitter 支持“Token / Cookie 登录”（可直接粘贴 40 位 auth_token 令牌、多字段导出文本、JSON 数组或完整 Cookie，自动换取 ct0 / twid 并补齐账号资料），Facebook 支持网页登录或粘贴含 c_user 与 xs 的 Cookie 字符串 / JSON 数组（并支持通过 i_user 无损切换 Profile+ 公共主页身份），YouTube 支持 Google 网页登录或粘贴含 SAPISID 与 SID 的 Cookie 字符串 / Netscape / JSON Cookie（并支持通过 Channel Switcher 切换品牌频道）。无需另做创作者登录；后续读取、发布与互动均复用该账号的独立环境与会话。

若暂时看不到账号，先检查顶部平台是否选对。登录失效时从账号列表重新登录，不要为了修复登录删除整个数据目录。

03 / FIRST RESULT

完成第一个任务：下载一条内容

先用自己拥有或获准保存的一条抖音、小红书或快手内容验证完整流程。视频号用户可以先在本账号管理同步自己的作品；要下载视频，先连接本机微信通道，再粘贴分享链接。

TikTok 新用户建议先做一次小规模关键词采集：选一个已登录账号、一个关键词、每词 5 条，先关闭评论与下载。确认有结果后，再逐项开启其他选项。

  1. 完成对应平台账号登录，复制一条作品的完整分享文案或链接。
  2. 打开“链接下载”，粘贴分享内容；如表单提供账号、画质或保存选项，选择刚登录的账号，其余先保留默认值。
  3. 提交下载，等待页面返回结果，不要连续点击。
  4. 查看下载历史和保存路径，到电脑上的对应目录确认文件。
完成标志：下载历史显示完成，实际文件可以打开。你已经验证了“本地服务 → 账号 → 任务 → 文件”这条流程。

默认下载内容位于 data/media/ 下；若修改过下载目录，请以界面或配置中的实际路径为准。失败时先看故障排查，不需要重新安装整个项目。

下一步：管理多平台多账号或统一审阅素材，阅读全平台矩阵与汇总预览；想自动发现更新，阅读作品监控；想一次性按词收集，阅读关键词采集。

全平台矩阵与汇总预览：高效统筹多平台多账号

入口：顶部「全平台」全局视角 → 指挥概览 / 汇总预览库 / 账号矩阵 / 矩阵数据与私信 / 矩阵群发

当管理多个平台或多个账号时，点击顶部切换栏最左侧的「全平台」即可进入跨十一大平台的全局矩阵视角（左侧菜单会自动收敛为全局汇总、矩阵运维与系统级模块）；点击任意具体平台（如抖音、小红书、Twitter、Facebook、YouTube）则聚焦该平台的采集、监控、单号管理与互动工具。

1. 指挥概览

  • 健康与待办快筛：顶部自动汇总登录失效、代理故障、同平台共用代理提醒、本机直连提醒、风控冷却、未读私信、失败/待审任务及 0 播异常作品，点击任意告警胶囊即可直达对应筛选视图处理。
  • 十一平台态势矩阵卡：一屏查看十一个平台的在线账号数、粉丝净增、启用监控数、今日入库作品与评论，支持勾选「折叠空平台」精简顶部切换栏，点击卡片即可切入对应平台。
  • 近期捕获与发布排期：同屏预览最新高赞入库内容、今日待发/发布中队列与近 7 日采集发布趋势。

2. 汇总预览库（四源合一分栏快览）

  • 统一内容源：将「作品监控」「批量采集」「自有账号作品」「分享链接下载」四类记录汇总到同一视觉画廊（支持切换紧凑列表），可按平台、内容源、视频/图集、点赞门槛、仅看本地已就绪与关键词组合筛选。
  • 右侧固定快览器：点击任一作品即可在右侧分栏直接播放本地视频、左右翻阅多图图集、查阅完整文案与本地已抓取的高赞评论，无需频繁弹窗；支持键盘 J / K 上下快速切换审阅，以及一键打开所在文件夹或带入矩阵群发。

3. 账号矩阵与批量运维

  • 跨平台人设分组与角色：支持新建跨平台矩阵分组（如将同一 IP 下的抖音、小红书、B 站、Instagram 账号归入同一人设组，配置色标与期望代理地区），并为账号设置备注别名、常用置顶与职能角色（创作主号 / 采集小号 / 混合通用）。
  • 三视图切换：提供「矩阵分组卡片」（按人设组聚合多平台账号）、「密集运维总表」（适合数十上百账号快速检索排序）与「浏览器运行墙」（集中查看正在打开的独立窗口并支持一键全关）。
  • 批量操作与连续扫码补登：勾选多个账号后可批量划入分组、设置角色、增改标签、从代理池均衡分配代理（优先空闲节点，池余量不足时最少占用复用并提醒）、一键切换本机直连、切换浏览器内核或顺序检测登录态；当存在多个失效账号时，点击「连续补登失效号」即可逐个唤起对应扫码流程高效恢复。

4. 矩阵数据对比、全平台聚合私信与多号错峰群发

  • 矩阵数据与私信：默认展示全矩阵账号粉丝/播放/获赞排行、跨账号已发作品墙（支持一键筛选 0 播预警或异常状态作品）以及全平台聚合私信收件箱；切换到具体平台后，点击「单账号精细管理」即可操作单账号作品同步、关注/粉丝列表与会话回复。
  • 矩阵多号错峰群发：在全平台「矩阵群发」或单平台「内容发布 → 矩阵多号群发」中，上传一次视频或图文素材与主文案，即可按矩阵组或「创作主号」一键勾选多平台目标账号（误选采集小号自动提示），设置错峰间隔分钟数（各账号按序顺延定时入队），并在右侧按平台实时核对标题字数上限、单独覆盖特定平台标题与可见范围。

作品监控：持续发现更新

入口：作品监控 → 新建作品监控

适用：抖音、小红书、海外小红书、快手、视频号、TikTok、哔哩哔哩、Instagram、Twitter、Facebook、YouTube。视频号监控需要先连接本机微信通道。

  1. 复制创作者主页的完整分享文案或链接。小红书与海外小红书可选择“创作者笔记”或“关键词”监控类型，并填写对应目标；链接尽量保留有效的 xsec_token。
  2. 粘贴目标，按需要使用“识别”，检查识别结果，再选择使用账号。
  3. 设置检查频率。第一次可先用“每 30 分钟”或“每小时”，而不是同时添加大量高频目标。
  4. 选择“自动下载范围”：只想观察结果时选“仅记录，不下载”；确实需要媒体时选择对应类型。
  5. 如当前平台提供“首次历史回填”，先选最近 5 条或不下载历史。分组、标签、下载目录和高级筛选可以稍后配置。
  6. 保存后在“监控目标”查看状态，在“作品记录”查看发现的内容。
为什么新建后没有旧作品？默认主要监控订阅后的新内容。历史回填与持续监控是两件事；没有新内容、尚未到检查时间、筛选过严，都可能导致暂时没有记录。

完成标志：目标出现在列表；执行后有检查状态，有符合条件的内容时出现在作品记录中。无需继续监控时，暂停目标，不要只关网页。

作品、评论、弹幕监控的新建与编辑均支持秒级频率。选择“自定义”后输入数值，并选择“秒”或“分钟”；范围为 1–86400 秒，分钟允许小数但须换算为整秒（例如 1.5 分钟 = 90 秒）。切换单位保持实际间隔，弹幕仍可选择跟随全局设置。配置是期望间隔，实际执行还受任务耗时、错峰和账号限速影响。

账号、历史与下载目录

  • 海外小红书：目标支持 www.rednote.com 创作者主页链接或搜索关键词，需绑定主站登录有效的海外小红书账号（推荐配置非中国大陆代理）。
  • TikTok：目标使用创作者主页、完整分享文案或 @username，识别后必须绑定有效的 TikTok 登录账号。主页作品读取使用浏览器；关键词采集的 native 设置不代表所有功能都不打开浏览器。
  • Instagram：目标支持创作者主页链接、@username 或纯数字 UID，绑定有效 Instagram 账号后默认优先通过协议接口读取主页动态与 Reels，兼容失败时按混合策略回退账号浏览器，并支持首次历史回填。
  • Twitter：目标支持 x.com/<username> 主页链接、@username、数字 UID 或单条推文链接（识别自动提取作者），绑定有效 Twitter 账号后默认优先通过 GraphQL 协议直连读取时间线，兼容受阻时自动回退账号隔离浏览器，并支持首次历史回填。
  • Facebook：目标支持个人主页、公共主页（含 /reels/、/videos/、/photos/、/posts/ 子标签页）、群组（/groups/...）链接或搜索关键词，绑定有效 Facebook 账号后默认优先走 SSR + 动态 GraphQL 协议直采并在冷启动或兼容受阻时回退账号隔离浏览器，支持首次历史回填。
  • YouTube：目标支持频道主页链接（youtube.com/@handle 或 /channel/UC...）或搜索关键词，绑定有效 YouTube 账号后默认优先走 SSR ytInitialData + Innertube Web 协议直采并在异常时回退账号隔离浏览器，自动覆盖常规视频与 Shorts 并支持首次历史回填。
  • 视频号：目标可填 v2_...@finder 创作者标识、主页链接，也可以直接粘贴一条 weixin.qq.com/sph/... 视频链接，点击“识别”会自动反查作者。视频号监控通过本机已登录的桌面微信读取，不需要也不能绑定网页账号；账号列显示“本机微信客户端”。支持首次历史回填。
  • 多账号订阅：抖音、小红书、海外小红书、快手支持不同执行账号分别订阅同一主页，各自维护扫描进度与采集策略。同账号同主页只保留一条任务，包括已暂停的任务；小红书与海外小红书关键词任务仍按关键词规则去重。
  • 历史回填：默认只关注订阅后的新内容。需要旧作品时在新建目标时选择回填数量，先用小批量验证。
  • 共享目录：多个任务写入同一路径的同一媒体时串行写入并复用已有文件；需要分开保存时，为任务配置不同目录。

批量采集：一次性收集一批结果

入口：关键词采集 → 新建任务；视频号入口为“作品批量采集”

抖音、小红书、海外小红书、快手、视频号、TikTok、哔哩哔哩、Instagram、Twitter、Facebook、YouTube 均支持关键词来源（Instagram 支持 #hashtag 话题分区，Twitter 支持搜索算子与 #hashtag，YouTube 支持按上传时间/时长/排序筛选）。抖音、小红书、海外小红书、快手、视频号、哔哩哔哩、Instagram、Twitter、Facebook、YouTube 还可按创作者主页（Facebook 同时支持公共主页与群组，YouTube 支持频道 /@handle 与 /channel/UC...）采集；小红书与海外小红书可选全部收藏或指定收藏夹；视频号、哔哩哔哩、Instagram、Twitter、Facebook 与 YouTube 支持本账号作品来源。下列步骤以关键词为例，其他来源按表单填写主页标识或收藏夹 ID。

选择创作者来源时，可以直接粘贴主页链接、短链或分享文案，点击输入框右侧的“识别”提取创作者标识，识别结果会显示在输入框下方。结果列表中带作者标识的作品，可点击标识复制，方便再建监控或采集任务。

  1. 输入关键词，一次最多 20 个。第一次先填 1 个容易理解的词，例如“摄影教程”。
  2. 选择可用账号，将每词作品数设为较小值，例如 5；不需要评论或媒体时关闭对应选项。
  3. 如需要评论，设置每作品评论数，并明确是否包含二级评论。数量代表上限，不保证达到该数量。
  4. 提交后查看任务进度和错误信息。等待本次采集结束，再检查结果和 Excel 导出。
  5. 需要继续采集时，可对已结束任务编辑配置并保留结果去重续跑，避免重复新建相同任务。

完成标志：任务结束，有结果可查看或导出；数量少于上限不一定是故障，结果受平台排序、登录状态和当前可见内容影响。

如何选择采集选项

范围与筛选
每词作品数、采集深度、排序、发布时间、作品类型及互动门槛共同决定结果；以当前平台提供的选项为准。数量、翻页深度或停止条件任一满足时任务都可能结束。
评论与媒体
按需设置每作品评论上限、是否读取二级回复、是否下载媒体及保存目录。先少量读取，再增加内容，避免一次任务同时承担所有需求。
结果与续跑
查看作品、评论、下载状态及具体错误，可导出 Excel。已结束任务可编辑配置并保留已有结果去重续跑；取消任务会保留已入库内容，部分完成时先查看失败项。

TikTok 读取模式

当前批量来源只支持关键词视频搜索，可附带评论、二级回复与媒体下载。“设置 → 采集与运行 → TikTok 关键词获取方式”对应 engine.tiktok_read_mode：

  • native（默认）：使用所选账号的 Cookie、UA 和代理进行离线签名后的网络请求，关键词、评论和二级回复不打开浏览器；失败直接显示原因，不自动切换页面。
  • auto：优先直连，兼容失败时可回退到可见浏览器。
  • browser：使用账号浏览器页面读取。

“离线签名”只是签名计算在本地完成，采集仍需要联网和有效登录态。用户搜索、主页作品读取、登录和写操作另有浏览器流程，不受“不打开浏览器”的关键词模式承诺覆盖。

海外小红书采集与读写通道

批量采集支持关键词、创作者主页、全部收藏与指定收藏夹来源，严格限定在 rednote.com 四域名体系下运行（推荐配置非中国大陆代理出口，支持本机直连）。“设置 → 采集与运行”中的 rednote_read_mode 默认采用 hybrid（纯 Python XYS / XYW + b1 签名协议直连优先，普通兼容受阻自动回退账号隔离浏览器；也可切换为 api 或 browser）。

Instagram 采集与读写通道

批量采集支持关键词 / 话题标签（#hashtag）、创作者主页与本账号作品来源，支持附带顶层评论、二级回复抓取及单图、视频或混合轮播图集下载。“设置 → 采集与运行”中的 instagram_read_mode 与 instagram_write_mode 默认均为 hybrid（协议直连优先，确认兼容受阻时回退账号隔离浏览器，也可固定为 api 或 browser）。

Twitter (X) 采集与读写通道

批量采集支持关键词、创作者主页与本账号推文来源，支持对话线程主回复与嵌套回复抓取、?name=orig 原图与最高码率 MP4 视频下载（纯文字推文自动标记为“纯文本”跳过媒体下载）。“设置 → 采集与运行”中的 twitter_read_mode 默认采用 hybrid（动态 GraphQL 与 Syndication / REST 协议直连优先，兼容受阻时自动回退账号隔离浏览器；也可固定为 api 或 browser），写操作与发布统一走隔离浏览器通道。

Facebook 采集与读写通道

批量采集支持关键词帖子搜索、个人/公共主页或群组时间线与本账号动态来源，支持附带主帖及 Reels 评论抓取与图片/视频下载（纯文字帖自动标记跳过媒体下载）。“设置 → 采集与运行”中的 facebook_read_mode 默认采用 hybrid（关键词搜索、主页/群组动态、单帖/Reels 详情与评论均优先走纯 HTTP SSR 与动态学习的 RelayModern /api/graphql/ 协议直采，零硬编码过期 doc_id，冷启动或版本变更时自动回退账号隔离浏览器一次并学习最新查询模板；也可切换为 api 或 browser），好友与 Messenger 收件箱及所有写操作与发布均通过独立隔离浏览器执行并支持 i_user 公共主页（Profile+）无损切换。

YouTube 采集与读写通道

批量采集支持关键词视频搜索、频道主页（同时覆盖 Videos 与 Shorts）及本频道作品来源，支持附带评论区抓取与 yt-dlp + 内置 FFmpeg 无损合流 MP4 下载。“设置 → 采集与运行”中的 youtube_read_mode 默认采用 hybrid（优先走 SSR ytInitialData 与 Innertube Web /youtubei/v1/* + SAPISIDHASH 协议直采，异常时自动回退账号隔离浏览器；也可切换为 api 或 browser），YouTube Studio 发布、多频道切换、评论互动与观看养号均通过账号独立隔离浏览器执行。

视频号采集来源

  • 关键词搜索 / 创作者主页：通过本机微信通道读取，“使用账号”显示为“使用本机微信通道（无需网页账号）”。创作者来源可填 v2_...@finder、sph 标识、主页链接，或单条视频的 weixin.qq.com/sph/... 链接（自动反查作者）。未连接微信通道时，任务会提示先去连接。
  • 本账号作品：选择已登录创作者助手的视频号账号，读取自己的视频与图文管理页。
  • 评论可读取主评论和二级回复；勾选下载媒体时，加密视频会在本地解密，并在保存前校验文件完整，校验不通过不会保存。
这不是定时监控。小红书与海外小红书需要有效的主站登录态；选择“最新发布”后会按发布时间处理候选。“页面可见但详情媒体未读取到”可能是访问参数过期或页面结构变化，不等同于账号失效。

评论与弹幕监控

评论监控

入口：评论监控 → 新建评论监控

适用于抖音、小红书、海外小红书、快手、视频号、TikTok、哔哩哔哩、Instagram、Twitter、Facebook、YouTube。海外小红书支持单条笔记与创作者近期作品的只读评论抓取（尽量保留有效 xsec_token）；Twitter 支持单条推文（/status/ 链接或数字 ID）及创作者近期推文的对话线程回复抓取；Facebook 支持单条帖子/Reel/Watch 链接或个人/公共主页与群组的评论监控；YouTube 支持单条视频/Shorts 链接或频道近期视频的评论监控。视频号单条作品可粘贴 weixin.qq.com/sph/... 分享链接或作品 objectId，账号近期作品可填 v2_...@finder 或主页链接；需要先连接本机微信通道，不绑定网页账号，可读取主评论和二级回复。TikTok 建议粘贴包含作者 @username 的完整作品链接，或使用创作者主页监控近期作品；任务必须绑定有效的登录账号。

  1. 选择单条作品或账号近期作品的监控方式，填写相应链接或目标。
  2. 选择已登录账号，按需设置检查周期与采集选项；第一次减少目标数量，其他参数先保留默认。
  3. 保存后查看“监控目标”的状态，执行后到“评论记录”查看结果。
  4. 看不到数据时检查目标是否有可见评论、登录是否有效，以及筛选条件是否排除了结果。

评论监控是读取和保存评论，不会因为你创建了监控就自动发出回复。回复规则见自动评论与审核。

弹幕监控（抖音短视频 / 哔哩哔哩视频）

入口：切换到抖音或哔哩哔哩 → 弹幕监控 → 新建弹幕监控

  1. 填写视频目标并选择账号；自己的视频使用创作中心来源，公开视频使用播放器来源。
  2. 设置视频内时间范围，按需添加关键词、文本长度、点赞数和容量上限。
  3. 保存并等待执行，到“弹幕记录”查看按视频时间点排列的结果。

弹幕时间是视频播放时间轴上的位置，不是评论发布时间，也不是直播弹幕。评论区有内容不代表视频中一定有弹幕。

链接下载：保存已知内容

入口：链接下载

  1. 从对应平台复制完整分享文案，不必手动删掉文案中的文字。
  2. 粘贴到输入框；按需选择账号、画质和下载选项，再提交。
  3. 查看下载历史或错误提示，成功后检查实际保存路径。

抖音与哔哩哔哩支持画质选择（哔哩哔哩支持 BV/av 视频高清音画自动无损合成及图文动态下载），小红书与海外小红书支持无水印图集与视频，Instagram 支持 /p/、/reel/、/tv/ 单图、视频及最多 10 项混合轮播图集按序保存，Twitter 支持 x.com / twitter.com / t.co 推文链接的 ?name=orig 原图（最多 4 张）与最高码率 MP4 视频保存，Facebook 支持帖子/Reel/Watch 链接与 fb.watch 短链图片及视频保存，YouTube 支持 watch / shorts / youtu.be 链接高速识别与 yt-dlp + FFmpeg 无损合流 MP4 下载，快手支持内容下载；TikTok 也可随关键词采集或作品监控下载视频。链接下载对 TikTok 等站点使用通用提取器，成功与否受链接可访问性和提取器兼容性影响。

视频号：粘贴 weixin.qq.com/sph/... 分享链接或作品链接。未连接本机微信通道时，只能通过公开预览读取标题、作者和封面，不能下载视频。连接后会取得视频地址并在本地解密，保存前校验文件可以正常播放，校验失败不会保存。

下载有断点续传和失败重试机制，但链接失效或登录失效仍需要先修复原因。高画质取决于平台实际提供的资源；“仅音频”、格式处理或音画合并出现问题时，先更新依赖，必要时检查 ffmpeg。

分享链接命令行下载

在仓库根目录、已激活的虚拟环境中执行。只解析文案中的地址，不访问网络：

python -m app.engine.share_downloader --links-only "完整分享文案或链接"

下载到指定目录，并请求 1080 画质（实际以源资源为准）：

python -m app.engine.share_downloader "完整分享文案或链接" -o ./data/media/share -q 1080

发布、转发与矩阵群发

入口：单平台 → 内容发布（撰写内容 / 矩阵多号群发 / 发布记录）；全平台 → 矩阵群发

统一风控规则与场景方案

  • 队列统一展示采集、发布、自动评论、账号动作和下载任务，可按平台、类型、状态与关键词筛选。
  • 默认全部关闭、所见即所得：初始默认 risk_control.enabled: false、mode: custom，夜间休眠、写操作额度限制、随机错峰与 native 写入门禁均默认关闭；页面内显示的数值即为开启后的真实生效值，不再暗中覆盖用户输入。
  • 一键场景方案 + 6 项独立模块：在「风控中心 → 风控规则」可一键套用「关闭风控 / 轻度防护 / 稳妥防护 / 严格保守」，也可独立开关「异常自动冷却与恢复」「写操作频率与额度」「读写防抖与连续休息」「夜间休眠（活跃时段）」「同出口防连坐」「自动任务随机错峰」，并按需展开微调参数。

账号隔离与代理

每个账号有独立的持久化浏览器 Profile、底层语言首选项、确定性硬件指纹种子与 TLS 握手指纹，Cookie、缓存和本地存储互不共享，也与日常个人 Chrome 配置完全分开。浏览器环境默认阻断非代理 WebRTC UDP 旁路泄露；Profile 带有跨进程占用保护，不要让其他 Chrome 进程同时打开项目账号的 Profile，也不要随意删除它。

弹性代理、跨区防错配与防关联风险提醒：系统不强制要求「一号一代理」，也不阻断「本机直连」——无论是无代理直接走本机网络，还是在同区代理节点较少时多个账号复用同一代理，均可正常完成登录、浏览器打开与读写任务。自动分配严格区分国内与海外平台（国内平台仅自动匹配中国大陆或未测节点，海外平台仅自动匹配非中国大陆或未测节点，绝不将反方向地区节点自动错配以免连接被拒）。当检测到海外平台本机直连、同平台多账号共用本机 IP或同平台多账号共用同一代理 / 出口 IP时，结构化代理选择器、全局大盘、账号矩阵与风控中心会自动高亮防关联提醒，建议多账号矩阵与海外平台尽量配置独立住宅代理以降低同 IP 连坐风险。socks5:// 代理在协议与下载通道会自动升级为远程 DNS 解析（socks5h://）以防本地 DNS 污染。

代理池管理与批量导入：支持 HTTP、HTTPS、SOCKS5 及账号密码认证。除标准代理 URL 外，单条添加和批量导入均原生识别服务商常见的六种导出格式：主机:端口:用户名:密码、主机,端口,用户名,密码、主机:端口@用户名:密码、用户名:密码:主机:端口、用户名:密码@主机:端口、主机:端口##用户名##密码；未填备注时可按探测到的出口归属地自动命名，批量导入支持自动并发测速补齐归属地。代理池面板支持按连通状态、空闲/已绑、大陆/境外快速筛选及多选批量测速、按地区命名、启停与删除，并直接展示每个节点绑定的具体账号胶囊与网关通道特征标识；节点“编辑”支持同时修改备注、完整代理地址与账密并自动同步给关联账号。同出口多个账号集中触发风险时，可进入出口组熔断。不要把代理密码或账号 Profile 分享到公开反馈中。

国内版小红书优先系统 Chrome/CDP；自动模式在未安装 Chrome 时可回退到可见 Patchright Chromium，实际后端可在账号列表确认。Fingerprint Chromium 是其他平台（含海外小红书、TikTok、Instagram、Twitter 等）的进阶可选项，国内版小红书不使用该组合；海外平台代理池自动分配仅挑选非中国大陆（或未测）节点，国内平台仅挑选中国大陆（或未测）节点。普通上手无需安装额外指纹浏览器。

入口：设置 → 视频号微信通道；视频号采集表单中的“配置本地微信通道”也会跳到这里

视频号的关键词搜索、他人创作者主页、作品与评论监控、全量评论和加密视频下载，都通过本机已登录的桌面微信读取，不需要创作者助手账号。本账号作品同步、数据和发布仍使用创作者助手登录。只用本账号功能时可以不配置。

  1. 点击面板上的“一键连接本机微信”（首次使用会自动请求安装仅签发 channels.weixin.qq.com 的本机根证书，在系统弹窗点击“是”即可；之后自动跳过）。

  4. 点开链接后页面会自动检测变绿完成连接，无需手动点击检测；此后重启 CreatorHub 也会自动恢复通道与已开桥接窗口连接。
完成标志：状态显示“已连通微信视频号”，能力列表中的关键词搜索、任意创作者主页、全量二级评论和视频解密都显示为可用。
  • 代理范围：只处理 channels.weixin.qq.com，其他网站的 HTTPS 流量原样加密转发。不用时点击“停止”；服务异常退出后，下次启动会自动恢复备份的系统代理。
  • 系统代理托管失败：被其他代理软件或权限限制拦截时，可取消勾选自动托管，再手动把 channels.weixin.qq.com 的流量指向本地代理端口。

未连接时，视频号分享链接只能读取标题、作者和封面；关键词、他人主页和评论任务会提示先连接本机微信。对应配置项如下，页面保存的设置优先：

  channels_cdp_endpoint_file: ""  # 可选：WMPF 控制口令文件

AI ASSISTANT & MCP

AI 助手与 MCP

入口：任意页面右下角「AI 助手」→ 助手 / 历史记录 / 模型设置

任意页面右下角的「AI 助手」会打开全局浮窗，支持数据问答、任务诊断，以及关键词采集和作品监控的工作流草稿。模型设置与历史记录全局共用，不再作为独立侧栏页面。功能默认关闭，与设置页的「AI 文案」独立；启用后，所选范围内的脱敏数据摘要会发送到你配置的模型服务，可能产生模型调用费用。

  1. 创建或编辑渠道：点击右下角「AI 助手」，进入「模型设置」。可在渠道列表编辑已有渠道，或点击「添加模型渠道」，依次填写显示名称、API 地址、API 协议和 API 密钥。协议可选 OpenAI Chat Completions（含兼容服务）、OpenAI Responses 或 Anthropic Messages。
  2. 填写服务地址：API 地址可填域名（https://HOST）或带前缀的基础地址（https://HOST/v1），不带 /models 或查询参数。只填域名时，模型目录先读取 /models，仅在该路径返回 404 / 405 时再尝试 /v1/models；目录探测不触发生成请求。推理接口默认在纯域名后补 /v1，已有前缀保留；自定义根路径服务可在高级设置选择「原样拼接」。支持相同协议的本地模型服务可留空密钥。
  3. 同步与选择模型：点击「获取可用模型」，在「选择模型」弹窗中搜索、勾选所需项，然后点击「更新目录」。取消或按 Esc 不修改目录。已加入的模型可逐行编辑显示名称、点击配置按钮修改 ID，或移除；再从「当前使用的模型」中选择本次使用的模型。也可点击「添加模型」手动录入，或直接填写目录外的模型 ID。获取目录使用当前表单信息，无需先保存或启用，不调用生成接口；确认选择后仍需「保存配置」才会持久化。密钥留空时只复用同一服务已保存的密钥。
  4. 启用并验证配置：勾选启用，保存并测试配置。最多保存 20 个独立渠道；新增和编辑非当前渠道不会自动切换，点击「使用」或在助手页选择「当前渠道」后才用于后续分析。启用开关、名称、目录和高级设置随渠道保存；新渠道不继承旧密钥。「取消」放弃未保存修改；删除需确认，当前渠道须先切换后再删除。连通测试验证文本响应；任务分析会进一步验证工具调用。不支持工具调用的模型可在「高级设置」关闭该选项，仅用于读取预先收集证据的问答与诊断。MCP 与调用限制也在高级设置中。
  5. 发起问答或诊断：回到「助手」，选择跟随页面平台、指定平台或全平台，再选择账号和工作模式，输入问题。诊断模式还需选择具体任务；打开采集任务详情后可点击「带入当前任务进行诊断」。结果下方可查看执行步骤和证据。
  6. 核对并确认工作流：生成草稿后核对每一步的平台、账号、目标、数量、频率、下载选项及未支持事项，勾选确认后创建任务。创建成功不等于平台执行完成，请到原业务页面跟踪。

获取模型返回 401 表示上游鉴权未通过，不是「没有模型」。界面会提示本次是否携带 Key：未携带时填写密钥，已携带时检查密钥有效性、所属服务和协议。目录最多处理 1000 条，截断时会提示；空目录、服务未开放目录或获取失败时仍可手动填写 ID。模型出现在列表中不代表已通过工具调用验证。

若提示未返回 SSE，需检查网关是否支持并启用了流式输出；不会自动切换为非流式请求。若提示返回 HTML，通常是推理路径落到网站页面而非模型接口；检查 /v1 前缀和路径模式。HTTP 403 表示推理请求被上游拒绝，需检查密钥的模型/接口权限和访问策略；获取模型目录成功不代表推理权限可用。响应诊断不回显密钥和上游原文，不自动重试付费请求。更新多渠道功能后请重启后端，再强制刷新页面。

像聊天一样连续追问

助手采用消息气泡与底部固定输入框。按 Enter 发送，Shift+Enter 换行；中文输入法选词时不会误发送。回复可复制，支持标题、列表和代码块；「执行记录与证据」默认折叠，需要时再展开。工作流仍在消息卡片中核对并单独确认。

顶部选择「当前渠道」和「本次模型」；本次模型只作用于当前消息，不修改渠道默认值，同渠道可以换模型继续追问。「对话选项」中选择范围、账号和模式；切换范围、任务或渠道后会提示下一条开启新对话，原消息仍保留。模型回复不代表已执行修复或创建任务。

点击顶部加号可新建对话，不删除历史，保留未发送的草稿。「历史记录」按对话归组，可搜索并打开继续聊；打开记录不会重新调用模型。界面显示最近 30 轮，每次追问最多参考前 8 轮、约 20,000 字符的历史问答，并重新读取当前证据。更早消息仍保留在本地；旧版分析记录可查看，新问题会另起对话。

浮窗可展开或收起，也可按 Esc 收起。当前浏览会话内，切换页面、平台或收起浮窗会保留输入、配置编辑与对话；收起不停止正在进行的分析。消息标明提交时的原平台范围，不会因当前页面切换而改变。若要终止模型调用，请使用「停止分析」，下一条输入草稿会保留。刷新整个网页后可从「历史记录」重新打开已保存对话。三种协议均只发流式请求，正文和上游公开推理随接收到的片段实时显示；没有非流式开关或回退。停止或断流会保留已收到的部分内容并标记未完成；浏览器断连只重新订阅同一记录，不重新调用模型。

查看推理内容与 token 消耗

有上游推理内容时，回复上方显示「思考 / 推理内容」，接收期间默认展开，可随时收起；完成后展开可看各次模型调用返回的摘要或文本；只有加密内容或没有返回时会明确提示，不使用工具日志模拟思考。若模型需要显式开启，可到「模型设置 → 高级设置 → 推理 / 思考请求」按协议选择：Responses 请求摘要，Anthropic 选择自适应或旧版预算思考，支持 thinking 参数的兼容接口可启用该参数。默认不附加参数，模型或网关须支持所选方式；启用可能增加耗时和消耗。

每条回复下方直接显示输入、输出、总消耗 token，包含工具往返中的多次模型调用；返回了推理或缓存明细时也会列出，明细已包含在输入 / 输出中，不重复累加。「执行记录与证据」可看逐次用量。当前加载对话另有已知消耗合计；历史更早的未加载消息不计入此数。

用量随上游流式 usage 事件更新，部分服务仅在结束时返回。单次调用累计统计以最新值为准，工具往返的不同调用再求和，不按文字长度猜测。未收到 usage 显示「—」，不是 0；部分回执缺失、旧版记录会标注。失败或停止也可能已经产生消耗，已返回的统计仍保留。计费金额仅在上游返回明确金额与币种时展示，否则提示查上游账单；token 总数不是实际金额，也不是账户剩余额度。

执行边界：AI 不自动发布、发送私信、删除数据、解除风险控制或修改项目代码。首版不包含无人值守自修复、定时 AI 日报或外部 MCP Client。业务任务仍由原有引擎执行，本地服务关闭后不继续运行。

模型调用与记录

每次分析最多 180 秒、12 次工具调用，轮数和单次输出上限可配置；同时最多两项分析。超时、停止或服务重启后不会自动重新付费调用模型。分析和草稿保存在本地数据库，包含问题、脱敏证据和工具记录。API Key 不回传到页面，但与现有设置一样保存在本机数据库中，请保护数据库与备份，不要公开分享。

更换模型地址或协议时须重新输入或明确清除密钥，避免把旧密钥发送到新服务。对兼容接口可选择 max_tokens 或 max_completion_tokens。Gemini 等服务可通过其兼容接口或自行部署的协议适配网关接入；这不代表所有模型均支持工具调用或多模态输入。当前助手处理文本与结构化业务数据。

连接外部 MCP 客户端

首版提供独立 stdio 服务，仅开放 list_accounts、list_tasks、get_task、get_metrics 和 get_risk_events。先启动本地工作台并保存「开放本机 MCP 查询」。MCP 查询本身不调用模型，外部客户端使用模型时按其配置计费。

源码用户在项目根目录创建独立环境安装可选依赖；无需更改主程序依赖：

.venv\Scripts\python.exe -m venv .venv-mcp
.venv-mcp\Scripts\python.exe -m pip install -r requirements-mcp.txt

客户端配置示例：将两个路径替换为本机项目的绝对路径；端口使用实际工作台端口。安装版用户也可单独取得源码中的 app/agent/mcp_server.py 和 requirements-mcp.txt，用独立 Python 环境运行桥接进程。

{
  "mcpServers": {
    "creatorhub": {
      "command": "D:/PATH/creatorhub/.venv-mcp/Scripts/python.exe",
      "args": ["D:/PATH/creatorhub/app/agent/mcp_server.py"],
      "env": {"CREATORHUB_URL": "http://127.0.0.1:8000"}
    }
  }
}

macOS/Linux 使用 .venv-mcp/bin/python。桥接只接受回环地址，不将工作台暴露到外网，也不访问数据库文件。停用 MCP 查询开关后，后续查询会被阻止。

更新、备份与恢复

Windows 安装版

从 v0.2.0 起，默认每天后台检查一次版本，只提醒、不自动下载。看到提醒后点击“一键更新”，下载完成再确认“安装并重启”；也可在“偏好设置 → 版本与更新”关闭自动检查或手动检查。下载支持增量优先、完整包兜底和断点续传，更新保留用户数据。没有一键更新入口的旧版先“停止并退出”，再运行新版安装包。

安装版默认用户目录是 %LOCALAPPDATA%/CreatorHub/user-data/，配置与 data/ 在此，不在程序安装目录中；即使安装时自定义选择了其他磁盘目录（或重新运行安装包迁移程序位置），原有用户数据也完整保留，一键更新会原地更新当前程序安装目录。可在启动中心「文件与数据」同时查看程序安装目录与用户数据目录；设置过 CREATORHUB_DESKTOP_HOME 时按实际位置备份，自定义媒体或 Profile 路径也需单独保留。

源码版：先备份，再更新

  1. 暂停重要任务并停止本地服务，避免复制正在写入的数据库。
  2. 将 config.yaml 和整个 data/ 复制到项目之外的私人备份目录。若自定义了数据库、媒体或 Profile 路径，也要备份这些实际目录。
  3. 记录当前版本或提交号。Git 安装用户在工作区无待处理修改时执行 git pull --ff-only；有冲突先处理，不要强行覆盖。
  4. ZIP 安装用户将新版本解压到新目录，再把备份的配置与数据复制进去；不复用旧的 .venv。
  5. 运行安装命令更新依赖，然后正常启动，检查账号、配置和历史记录。
# Windows
.\start.cmd install
.\start.cmd

# macOS / Linux
./start.sh install
./start.sh

数据库字段通常在启动时自动迁移，不需要为升级清空数据库。若需要回滚，停止服务，使用更新前的代码和配套的更新前数据备份，不要直接让旧代码读取已经迁移的数据。

备份包含敏感信息。Profile、Cookie、数据库、私信和通知密钥只保存在可信位置。换电脑恢复后可能仍需重新登录；不要把备份上传到公开仓库。

常见问题：先按现象排查

浏览器查找快捷键：Windows / Linux 按 Ctrl + F，macOS 按 ⌘ + F，搜索错误关键词。

打开 127.0.0.1:8000 提示连接失败

确认启动终端仍在运行且没有报错，首次依赖安装已完成，地址与启动端口一致。若端口被占用，运行 .\start.cmd --port 8080 后打开 http://127.0.0.1:8080。不要在另一台电脑上用 127.0.0.1 访问这台电脑。

双击启动一闪而过 / 找不到 Python

按安装章节在终端中启动以保留错误信息。确认安装了 Python 3.10+ 并加入 PATH，重新打开终端；Windows 可用 py -3 --version 查看版本，macOS / Linux 使用 python3 --version。

依赖下载失败 / 找不到 Chromium

先检查网络和磁盘，再在项目目录运行 .\start.cmd install（macOS / Linux：./start.sh install）。若仍提示浏览器缺失，使用项目虚拟环境修复，避免把浏览器装到另一个 Python 环境：

# Windows
.\.venv\Scripts\python.exe -m patchright install chromium
# macOS / Linux
./.venv/bin/python -m patchright install chromium
扫码没有弹窗 / 服务器没有桌面

扫码需要桌面环境，检查窗口是否最小化、后台打开或被其他窗口遮住。无桌面的服务器不是本指南的入门运行方式；先在自己的桌面电脑完成安装与登录。

小红书出现设备安全验证

使用本机稳定版 Chrome，保持原账号 Profile 和网络稳定，在当前浏览器窗口完成平台验证。自动任务会暂停，不要反复刷新、重新建号或删除登录目录。

小红书 / 海外小红书可以看内容，但发布失败

主站扫码登录与创作者登录相互独立。先完成创作者登录（海外小红书使用 creator.rednote.com 并确认非中国大陆代理出口有效，切勿混用国内版 Cookie），再检查素材与字数要求及发布记录。若提示“结果待确认”，先在平台核对，不要立即重发。

链接解析失败 / 作品或评论为空

确认平台选对、账号有效、作品在浏览器里可见，重新复制完整分享文案。小红书保留有效的 xsec_token。检查任务执行时间、历史回填、筛选条件及平台本身是否有可见结果。

视频号提示“需要连接本机已登录微信”

关键词搜索、他人主页、评论监控和视频下载都依赖本机微信通道。到“设置 → 视频号微信通道”确认根证书已安装、代理已启动，并在桌面微信里打开过一次视频号页面；状态显示“等待模块加载”时稍等再点“检测微信连通”。读取策略设为 browser 时不会使用本机微信。

开启视频号代理后网页打不开 / 系统代理没恢复

先在“视频号微信通道”点击“停止”，会恢复启动前备份的系统代理。软件异常退出时，下次启动会自动恢复。仍不正常时，到 Windows“设置 → 网络和 Internet → 代理”检查并关闭指向 127.0.0.1 的手动代理。

下载成功但找不到文件 / 没声音 / 画质不够

查看下载记录与当前保存目录，默认文件在 data/media/ 下。媒体处理异常先更新依赖；项目可使用 Python 依赖附带的 ffmpeg，也可使用加入 PATH 的系统 ffmpeg。画质还受源资源限制。

看到“本机直连提醒”或“共用代理提醒”会影响任务运行吗？

不会拦截任务。这两项属于非阻断式的防关联风险提醒，登录、浏览器与自动任务均可照常执行；仅当账号已显式绑定了代理且该代理连接故障或被停用时，任务才会暂停等待修复（也可在账号“代理”中清除代理改走本机直连）。若同平台运营多个核心账号，仍建议尽量在“代理池”配置独立住宅代理实现一号一 IP。

登录报错 ERR_SOCKS_CONNECTION_FAILED，或代理池显示“可连接”但打不开抖音 / 小红书？

代理池通用测试访问的是海外公共测速接口（ipinfo.io / ipify.org），而绝大多数海外住宅代理服务商（如 IPWO 等）出于合规策略会在服务端拦截发往中国大陆域名（douyin.com、xiaohongshu.com、bilibili.com 等）的连接请求，导致浏览器报 ERR_SOCKS_CONNECTION_FAILED。登录抖音、小红书、快手、视频号、哔哩哔哩等国内平台时，请使用本机直连或配置中国大陆出口代理；海外住宅代理专供 TikTok、Instagram、Twitter、海外小红书使用。

任务一直等待，重启后也没有立即执行

查看“任务队列”和“风控中心”的账号状态，确认审核、活跃时段、限额、共享间隔、代理和风险冷却。等待不是卡死的充分证据，重复提交可能制造重复任务。

Windows 提示浏览器子进程错误

先使用项目启动脚本和单 worker，不要额外添加 --workers。运行 .\start.cmd install 更新依赖，仍失败时保留完整错误日志。

macOS 安装提示 clang++ failed

先备份数据并更新项目，停止服务，把项目内的旧 .venv 重命名留作排查，再执行 ./start.sh install 重建环境。不要改动系统 Python 或误删 data/。

能把本地面板直接暴露到公网吗？

入门时保持默认回环地址，仅在本机使用。面板管理登录态及真实发布操作，公开访问需要另行评估身份认证、访问控制和网络保护，不要直接做公网端口映射。
